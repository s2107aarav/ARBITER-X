# Validation

Build and run the suite with CMake and CTest as shown in the README.
`scripts/reproduce_all.sh` exercises the complete core reproduction workflow.
GitHub Actions checks GCC 13, Clang 18, Apple Clang, and ASan/UBSan.

The core suite covers matching semantics, randomized differential streams,
protocol mutation, risk reservations, transport faults, journal recovery,
snapshot continuation, forks, and latency allocation. Regression cases cover
bounded input parsing, buffered journal closing, corrupt corpus files,
reference-book copies, self-trade accounting, delayed partial-fill reports,
zero arrival rates, and repeated execution at the horizon.

CLI checks exercise invalid options and configuration, nested output paths,
reference/optimized replay, and recovery from a corrupt journal tail. The
package check installs and relocates the library, then builds and runs a
separate CMake consumer against its public headers.

All three retained FLAGSHIP records can be checked with
`arbiter flagship --reproduce experiments/FLAGSHIP-<study>/results.json`.
Records are regenerated by the runner when engine corrections change their
results; their definitions and recorded provenance identify the study.

Full-world snapshots use format 15 and explicitly reject format 14. Journal,
wire, and book-checkpoint formats retain their existing formats. State hashes
are noncryptographic fingerprints; failed restoration is not guaranteed to be
transactional. Restore into a fresh World and discard it on failure.

See [verification](VERIFICATION.md) for coverage and
[performance](PERFORMANCE.md) for hardware, workloads, and benchmark evidence.
